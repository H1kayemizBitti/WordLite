图片：选中后双击可打开“图片设置”，支持精确宽高、对齐、文字环绕、裁剪和更换。表格：拖动列边线调整列宽，选中多个单元格后可合并，插入标签页可设置边框和底色。

打开文件与多窗口

  • 应用内打开（打开按钮 / Ctrl+O / 最近文件）：留在当前窗口；有未保存更改时会提示「保存 / 不保存 / 取消」。
  • 外部打开（拖入窗口 / 右键「打开方式」/ 双击关联文件）：新开独立窗口，原窗口保留，方便并排对比。
  • 空窗口拖入文件会原地打开；多个窗口各自独立保存和确认，互不覆盖。

编辑与排版

  • 功能区分为「开始 / 插入 / 布局 / 文件 / 更多」，常用操作都在「开始」。
  • 双击图片打开图片设置；表格可拖动列边线、合并单元格、设置边框和底色。
  • Ctrl+F 查找、Ctrl+H 替换；F1 随时打开帮助。

打印与 PDF

  • Ctrl+Enter 插入手动分页符；打印预览按分页符分页。
  • 导出 PDF 使用系统打印引擎，纸张和页边距跟随「布局 → 页面设置」。

自动保存与恢复

  • 默认每 2 分钟写一次恢复副本（可在「更多 → 设置」修改或关闭）。
  • 意外关闭后重新打开会提示恢复；正常保存或选择「不保存」后清理。
  • 恢复文件位置：%APPDATA%\com.h1kayemizbitti.wordlite\autosave-*.json

已知限制

  • DOCX 中的文本框、嵌套表格、复杂域会被简化。
  • 图片文字环绕支持左右两种。
  • 打印分页以分页符为准，长段落自动换页位置可能与屏幕略有差异。

离线、轻量的桌面写字板

打开就写，写完就存。不联网、不登录、不收集任何数据。
