图片：选中后双击（或按 Enter）打开右侧编辑面板，支持精确宽高、对齐、文字环绕、裁剪和更换；改宽度、环绕时正文实时重排，按 C 进裁剪，Enter 或 Ctrl+Enter 完成（裁剪状态下 Enter = 应用裁剪），Esc 取消，一次编辑只占一步撤销。选中图片后按空格、或右键「查看大图」可打开只读的查看器（滚轮缩放、拖动平移，不改文档）。表格：拖动列边线调整列宽，选中多个单元格后可合并，插入标签页可设置边框和底色。

打开文件与多窗口

  • 应用内打开（打开按钮 / Ctrl+O / 最近文件）：留在当前窗口；有未保存更改时会提示「保存 / 不保存 / 取消」。
  • 外部打开（拖入窗口 / 右键「打开方式」/ 双击关联文件）：新开独立窗口，原窗口保留，方便并排对比。
  • 空窗口拖入文件会原地打开；多个窗口各自独立保存和确认，互不覆盖。

编辑与排版

  • 功能区分为「开始 / 插入 / 布局 / 文件 / 更多」，常用操作都在「开始」。
  • 拖动：选中文字后可直接拖到另一段，按住 Ctrl 拖是复制，格式一起跟着走，一次拖动只占一步撤销；图片也能在文档流里拖动，落在图片前后的位置。拖到窗口上下边缘会自动滚动。拖过图片的选区会给选区里的图片蒙一层高亮。
  • 双击图片（或选中后按 Enter）打开右侧编辑面板；改宽度、环绕时正文实时重排，按 Enter 或 Ctrl+Enter 完成（光标在输入框里时 Enter 只确认那一个字段）、Esc 取消。
  • 图片面板里点「裁剪…」或按 C 进裁剪：图片露出完整原图，拖四边四角调框，可按自由 / 原图 / 1:1 / 4:3 / 16:9 / 3:4 锁定比例；Enter 应用、Esc 取消，手柄可用 Tab 聚焦、方向键每次 1px（Shift 10px）。
  • 查看大图：右键「查看大图」、图片面板里的按钮，或选中图片后按空格。滚轮缩放（10%–800%，以指针为中心，Ctrl+滚轮和触控板捏合同样有效），拖动平移，双击在适合窗口和 100% 之间切换，Esc 关闭。只看不改，不改文档也不进撤销栈。
  • 右键菜单：在灰色区域、正文、表格、图片上右键都会弹出简写自己的菜单（复制 / 剪切 / 粘贴 / 全选 / 插入图片 / 图片设置 / 裁剪 / 查看大图 / 删除等），不会出现浏览器的「刷新」，误点也不会丢稿。没有鼠标时按 Shift+F10 或菜单键也能弹出，方向键选择、Enter 执行、Esc 关闭。F5、Ctrl+R、Ctrl+Shift+R、Windows 上的 Alt+← 都不会重载文档；正文里的 Ctrl+R 照常是「右对齐」。
  • Ctrl+F 查找、Ctrl+H 替换；F1 随时打开帮助。

打印与 PDF

  • Ctrl+Enter 插入手动分页符。Ctrl+P（或功能区「打印」）直接打开系统打印页，页码范围、份数、纸张和预览都在那里调；简写不再有自己的打印预览窗口和页码 / 份数输入框。
  • 打印时不再印日期、文档标题和网址：系统打印页的「页眉和页脚」复选框在 Windows 上默认就是不勾选的。如果打印出来仍带着这些内容，在那个复选框上取消勾选即可。
  • 导出 PDF 使用系统打印引擎，纸张和页边距跟随「布局 → 页面设置」。

自动保存与恢复

  • 默认每 2 分钟写一次恢复副本（可在「更多 → 设置」修改或关闭）。
  • 意外关闭后重新打开会提示恢复；正常保存或选择「不保存」后清理。
  • 恢复文件位置：%APPDATA%\com.h1kayemizbitti.wordlite\autosave-*.json

已知限制

  • DOCX 中的文本框、嵌套表格、复杂域会被简化。
  • 图片文字环绕支持嵌入型、四周型（左 / 右）和上下型；紧密型、穿越型、衬于文字下 / 浮于文字上的环绕导入时会被简化。
  • 裁剪只改显示范围，原图完整保留（文件不会变小），导出的 DOCX 裁剪数据与这里一致。
  • 拖动文字和图片、裁剪时只支持鼠标；触摸屏长按拖动、裁剪里的滚轮缩放和框内平移将在 v1.2 提供。
  • 图片查看器只看不改，不能切换上一张 / 下一张，也不支持双指缩放。
  • 打印分页以分页符为准，长段落自动换页位置可能与屏幕略有差异。
